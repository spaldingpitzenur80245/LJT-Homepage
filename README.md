# Junteng Liu — Personal Homepage

Personal academic homepage built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Site content

- `_pages/about.md` — home page with academic background, research interests, research experience, publications, skills, honors and contact information.
- `_pages/publications.html` — publication list, generated from the publication collection.
- `_publications/` — individual publication records.
- `_config.yml` — site and author configuration.
- `_data/navigation.yml` — site navigation (About and Publications).

## Building and deploying

The `.github/workflows/jekyll.yml` GitHub Actions workflow builds the site with Jekyll and deploys it to GitHub Pages on pushes to `master`.
